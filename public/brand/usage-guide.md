# Brand usage — Sumenep Buku Kerja

Panduan lengkap sudah pindah ke [`README.md`](./README.md) di folder yang
sama: konsep, varian logo, warna, clear space, ukuran minimum, aturan
background, ikon aplikasi, dan larangan modifikasi.

Ringkas:

- Symbol adalah parent identity; lockup hanya menambahkan wordmark.
- Warnanya hanya token brand yang ada di `README.md`; gradient tidak pernah
  jadi struktur.
- Varian mono **wajib** memakai `logo-mono-*.svg` (satu warna, negative
  space antar halaman dipertahankan), bukan recolor dari lockup warna.
- Ikon aplikasi dibangun ulang dengan `bun run brand:build`, diperiksa dengan
  `bun run brand:check`.
